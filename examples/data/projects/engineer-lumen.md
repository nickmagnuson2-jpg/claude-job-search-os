- **Period:** 08/2016 – 07/2019
- **Role:** Software Engineer
- **Client:** Lumen Analytics
- **Industry:** Data Infrastructure / SaaS
- **Location:** San Francisco, CA
- **Type:** employment

## Description

Full-stack software engineer at an early-stage B2B data-infrastructure startup. Built customer-facing features and internal tooling for a platform that ingested and visualized analytics data for mid-market companies.

## Responsibilities

- Built and shipped customer-facing product features across the stack (Python backend, React frontend)
- Designed and maintained REST APIs consumed by enterprise customers' engineering teams
- Worked directly with customers' technical teams on integration and support escalations
- Owned data-ingestion pipeline reliability as the company scaled from 20 to 150 customers

## Key Achievements

- Shipped the public API that became the most-cited reason enterprise customers chose the platform
- Cut average integration time for new customers from three weeks to four days
- Frequently pulled into pre-sales calls to answer prospects' technical questions: the first hint that customer-facing work was the real draw
